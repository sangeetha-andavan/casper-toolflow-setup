# Source notes

This repository draft was organised from the user-provided PDFs:

- `Casper_Toolflow_Env_Setup.pdf` — toolflow installation, MATLAB/Vivado/Model Composer configuration, common build errors, ZCU216 part mismatch, Vitis backend, and device-tree configuration.
- `CasperFpga.pdf` — Python environment, `casperfpga` installation, SD-card image flashing, serial/Ethernet bring-up, board connection, register test, shutdown, and SD-card recovery.

Where the PDFs include risky or version-sensitive commands, the draft labels them as project observations and adds cautions rather than presenting them as universal fixes. Check the linked official documentation for the exact toolchain versions in use.
